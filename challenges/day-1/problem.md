# Day 1 Challenge: Responsive Greeting Card 🌱

## Objective
Create a digital greeting card that displays "Hello World" with a simple animation or interaction, using **HTML/CSS**, **Python**, or **JavaScript**.

### Requirements
  - **HTML & CSS**:
    - Use a `<div>` to structure the card.
    - Style it with CSS (background, border, centered text).
    - Add a fade-in animation for "Hello World".
    - Make it responsive (max-width: 600px).
  - **Python**:
    - Create a text-based card using ASCII art for "Hello World".
    - Add a simple animation (e.g., print letter-by-letter with delay).
  - **JavaScript** (with HTML/CSS):
    - Use the provided HTML/CSS card.
    - Add a click event to change "Hello World" to another message (e.g., "Welcome Back!") with a fade transition.
  - Keep it simple and clean!
  
### Hints
  - **HTML/CSS**: Use `display: flex` and `@keyframes`.
  - **Python**: Use `time.sleep()` for delay.
  - **JavaScript**: Use `addEventListener` and CSS `transition`.### Submission
  - Create your solution files.- Add them to `challenges/day-1/your-solution/`.
  - Submit a Pull Request!

### Example Output
  - A web card with fading "Hello World" (HTML/CSS).
  - A text-based card printed in terminal (Python).
  - A clickable card that changes message (JavaScript).
